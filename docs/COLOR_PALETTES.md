# 色卡管理与 JSON 格式

色卡管理是独立的配色资料工具，适合保存 UI 设计、图表或硬件项目的颜色方案。它不会自动修改应用主题，也不会把选中的颜色写入其他工具。

## 使用方式

1. 在侧栏打开「颜色 → 色卡管理」。首次使用会显示内置色板；内置的 35 种颜色只是示例，其他色板可包含任意数量的颜色。
2. 点击「新建色板」，填写名称和可选说明；通过「添加颜色」逐个加入颜色。点击色块可编辑名称和颜色，支持颜色选择器、六位 HEX、RGB，以及在运行环境支持时屏幕取色。
3. 点击颜色名称或 HEX 值可复制颜色。色板可折叠、编辑、单独导出或移除；一个色板的移除不会影响其他色板。
4. 点击「保存色板」才会把当前列表写入本机的应用存储。页面显示「有未保存的更改」时，离开页面前应先保存。点击「恢复默认」会清除已保存的列表并恢复内置色板。

本机保存使用应用 WebView 的 `localStorage`，键为 `embedded-toolbox.color-palettes.v1`。它与导出的 JSON 文件不同：清除应用数据或更换电脑不会自动迁移色板。需要备份或分享时，请使用「导出全部」。导出的是当前页面中的色板，包括尚未点击「保存色板」的更改。

## 导入与导出

- 「导入」可一次选择多个 `.json` 文件，也能读取单个色板或包含多个色板的合集。重复名称会自动附加编号，例如 `UI (2)`。
- 每种颜色需要非空名称和六位 HEX 值，例如 `#1261A0`。导入时也接受省略 `#` 的六位值，并统一转为大写。无效色板会被跳过。
- 「单独导出」用色板名称生成文件名；「导出全部」生成 `color-palette-collection.json`。文件使用 UTF-8 JSON，导出格式版本为 `4`。旧版示例文件的 `version: 3` 也可以导入。
- 仓库的 [`color-palettes/`](../color-palettes/) 保存了可直接导入的示例 JSON。它们只是示例数据，应用不会自动加载该文件夹。

单个色板的结构：

```json
{
  "format": "color-palette-manager",
  "version": 4,
  "encoding": "UTF-8",
  "name": "Dashboard Dark",
  "description": "Dark UI colors",
  "palette": [
    { "name": "Background", "color": "#20242A" },
    { "name": "Accent", "color": "#4DA3E5" }
  ]
}
```

合集使用 `format: "color-palette-manager-collection"` 和 `palettes` 数组；数组中的每一项包含 `name`、`description` 与 `palette`。

## 文件夹与命名

建议把需要长期保存的导出文件放在项目或设计资料的 `color-palettes/` 文件夹。新文件名使用小写英文、连字符和用途，例如 `dashboard-light-v1.json`、`dashboard-dark-v1.json`；包含多套方案的文件可命名为 `dashboard-palettes-v1.json`。同一色板更新后递增版本号，便于比较和回退。

应用不会指定下载目录。导出完成后，将文件移入目标文件夹即可。现有示例文件保留了原有文件名，不影响导入。
